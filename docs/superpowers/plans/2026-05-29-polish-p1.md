# Polish P1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline, this session) to implement task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. TDD throughout; Artisan-first for every artifact; run the Docker suite green before each commit.

**Goal:** Close the open `⚠️` acceptance criteria in PRD §4 (NEXT_STEPS Track 5) across F08/F09/F10/F11/F12/F13 as one front.

**Architecture:** Idiomatic Filament v5. The dashboard becomes a custom `Dashboard` page with `HasFiltersForm`; widgets read the date range via `InteractsWithPageFilters`. Exports use Filament's native `ExportAction` (openspout, already present). The dashboard PDF uses `barryvdh/laravel-dompdf`. Fee-override auditing extends the existing `Sale::updating` → `audit_logs` pattern.

**Tech Stack:** Laravel 12, Filament v5, Livewire 4, Pest 4, openspout (present), barryvdh/laravel-dompdf (new), DomPDF.

**Run commands** (no local PHP — Docker image `fa-test:php84`):
- Artisan: `docker run --rm -v "<repo>:/app" -w /app fa-test:php84 php artisan <cmd> --no-interaction`
- Tests (filtered): `... fa-test:php84 vendor/bin/pest --filter=<name>`
- Full suite: `... fa-test:php84 vendor/bin/pest --parallel`
- Pint: `... fa-test:php84 vendor/bin/pint --dirty --format agent`
